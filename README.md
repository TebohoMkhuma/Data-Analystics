# Data Analytics Skills Starter Project

This project contains starter assets for data analytics skills, including data loading, cleaning, analysis, visualization, and reporting.

## Structure

- `src/` – Python modules for data analytics workflows
- `data/` – sample data and datasets
- `notebooks/` – Jupyter notebooks for exploration and reporting
- `requirements.txt` – Python dependencies

## Setup

```bash
python -m venv .venv
.\.venv\Scripts\activate
pip install -r requirements.txt
```

## Run

```bash
python src/main.py
```
